# Bản gốc Standalone — KHÔNG SỬA

`pho-anh-hai/index.html` là bản game gốc độc lập (chạy offline, mở trực tiếp trên trình duyệt).

Quy tắc (chốt 2026-10-19 theo yêu cầu của chủ repo):
- **Không chỉnh sửa file này.** Mọi thay đổi gameplay/UI thực hiện trên module `js/games/pho-anh-hai.js`.
- File này là **tham chiếu gốc** để đối chiếu khi phát triển module: giao diện và cảm giác chơi của module phải giữ nguyên vẹn theo bản gốc.
- Module `js/games/pho-anh-hai.js` là bản tích hợp học từ vựng cho app Luyện Từ (đặc tả: `PHO_ANH_HAI_SPEC.md`).
