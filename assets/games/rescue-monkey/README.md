# Rescue Monkey Asset Pack

- `sprites/milo/`: các pose Milo.
- `sprites/yeti/`: các pose Yeti.
- `fx/`: bomb, rock, explosion, snow/ice/environment effects.
- `ui/`: HUD, panel quiz/typing, distance/warning.
- `sheets/`: sprite sheet gốc.
- `references/`: mockup màn chơi hoàn chỉnh.
- `demo/`: demo CSS/JS animation, chạy qua HTTP server.

Các file là tài sản tự tạo cho dự án clone, không lấy asset gốc từ Luyentu.com.
